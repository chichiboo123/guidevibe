# 가이드 바이브! ✊✌️✋

AI와 함께하는 나만의 앱 만들기 도우미

가이드 바이브!는 머릿속에 있는 앱 아이디어를 정리해, AI가 한 번에 알아들을 수 있는 요청 문장(프롬프트)으로 바꿔주는 단일 HTML 웹앱입니다. 초등학생도 쉽게 사용할 수 있도록 친근한 UI와 단계적 구조를 갖췄습니다.

---

## 라이브 데모

**[https://guidevibe.chichiboo.link](https://guidevibe.chichiboo.link)**

별도 설치 없이 브라우저에서 바로 사용할 수 있습니다.

---

## 주요 기능

1. **기본 정보 입력** — 앱 이름, 누가 쓰는지(주요 사용자), 한 줄 소개로 아이디어의 정체성을 정의합니다.
2. **디자인 설정** — 전체 분위기, 대표 색상(최대 5색), 글씨체(최대 3종)를 시각적으로 선택합니다.
3. **주요 기능 카드** — 기능 이름 / **사용자는 무엇을 하나요?** / **앱은 무엇을 해 주나요?** / 더 넣고 싶은 내용을 카드 단위로 구조화합니다. '사용자가 하는 행동'과 '앱이 해 주는 결과'를 나눠 적도록 안내해 초등학생도 쉽게 구분할 수 있습니다. 섹션 우측의 **예시 보기** 버튼으로 작성 예시 팝업을 확인할 수 있습니다.
4. **보조 기능 정리** — 효과음·사용법 안내·점수 저장 등 "있으면 좋은" 기능을 모아 둡니다.
5. **화면 만들기** — 휴대폰 모양 카드 위에 화면 이름과 설명을 직접 입력해 스토리보드를 만듭니다. 화살표로 순서를 바꾸면 번호가 자동으로 매겨지고, 비워두면 AI 자율 구성에 맡깁니다. 첫 번째 화면은 '처음 화면' 뱃지로 강조됩니다.
6. **프롬프트 자동 생성** — 입력한 모든 내용을 한 번에 AI 요청 문장으로 변환하여 복사 또는 TXT로 저장합니다.
7. **JSON 저장·불러오기** — 현재 작업 상태를 JSON 파일로 내보내고, 다시 불러와 이어 작업할 수 있습니다.
8. **자동 저장** — 입력 내용이 브라우저 localStorage에 자동 저장되어, 새로고침 후에도 유지됩니다.
9. **한국어·영어 전환** — 한 번의 클릭으로 인터페이스 언어를 전환합니다.

## 사용 방법

1. **[https://guidevibe.chichiboo.link](https://guidevibe.chichiboo.link)** 에 접속하거나, `index.html`을 브라우저에서 열어주세요.
2. 화면 상단의 **설명서** 버튼으로 사용법을 먼저 확인합니다.
3. 기본 정보 → 디자인 → 주요 기능 → 보조 기능 → 화면 만들기를 차례로 입력합니다.
4. **프롬프트 생성** 버튼을 누르면 하단에 AI 요청 문장이 나타납니다.
5. **복사** 또는 **TXT로 저장** 버튼으로 결과를 활용합니다.
6. 처음 사용한다면 **예시 불러오기**로 샘플 앱(감정의 숲·유튜브·카카오톡·틱톡) 중 하나를 먼저 살펴보는 것을 추천합니다.
7. 처음부터 다시 시작하려면 **초기화** 버튼을 누릅니다.

## 접근성·사용성

- 키보드 Enter 키로 카드/항목 추가
- 모든 모달 ESC 키로 닫기 지원
- 버튼·칩·스와치에 `aria-label`, `aria-pressed` 적용
- 색상 선택 시 칩과 HEX 코드 동시 표기

### 초등학생 발달단계를 고려한 설계

초등학생(구체적 조작기) 사용자를 위해 발달단계 연구에 근거하여 어휘와 인터페이스를 다듬었습니다.

- **쉬운 우리말 표현** — 영어 메타용어(What/How) 대신 '사용자는 무엇을 하나요?', '앱은 무엇을 해 주나요?'처럼 질문형 안내를 사용합니다.
- **구체적인 입력 예시** — 모든 입력칸에 '감정 날씨' 같은 실제 예시를 제시해 무엇을 적을지 막막하지 않도록 돕습니다.
- **부담 없는 안내** — "기능 이름만 써도 괜찮아요!"처럼 완성 압박을 줄이는 문구를 사용합니다.
- **큰 탭 영역과 글씨** — 화면 카드 조작 버튼(44px)과 글씨 크기를 키워 소근육이 발달 중인 어린이도 쉽게 조작할 수 있습니다.

## 자주 묻는 질문

**Q. 출력된 프롬프트를 그대로 다른 AI에게 붙여넣어도 되나요?**
A. 네. 단일 HTML 파일을 생성하도록 구조화되어 있어, 초기 프로토타입 제작에 적합합니다.

**Q. 화면 만들기를 비워두면 어떻게 되나요?**
A. 프롬프트에 "AI 자율 구성"으로 안내되어, AI가 적절한 화면 흐름을 제안하도록 합니다.

**Q. 작업하던 내용이 사라지나요?**
A. localStorage에 자동 저장되어 새로고침 후에도 유지됩니다. 다른 기기로 옮길 때는 JSON 내보내기/불러오기를 사용하세요.
