# 가이드 바이브! ✌️✊✋

AI와 함께하는 나만의 앱 만들기 도우미

가이드 바이브!는 초등학생도 이해할 수 있는 쉬운 글말과 명확한 UI를 통해, 앱 아이디어를 구조화하고 AI에게 정확히 전달할 수 있는 요청 문장(프롬프트)을 만들어 주는 단일 HTML 웹앱입니다.



## 주요 기능

1. 기본 정보 입력

* 앱 이름, 주요 사용자, 앱 소개 한 줄을 입력해 아이디어의 정체성을 빠르게 정의합니다.

2. 디자인 설정

* 대표 색상 최대 5개 선택
* 글씨체 최대 3개 선택
* 전체 분위기 한 줄 설명
* Google Fonts와 Tailwind를 사용하여 바로 시각 톤을 점검할 수 있습니다.

3. 주요 기능 정리

* 기능 이름, What, How, 추가 설명을 구조화하여 핵심 기능을 명료하게 기록합니다.
* 추가 버튼으로 여러 기능 카드를 생성하고 개별 삭제가 가능합니다.

4. 보조 기능 정리

* 배경음악, 튜토리얼, 저장, 점수 등 있으면 좋은 기능을 간단히 적어 추가합니다.

5. 페이지 구성(심화)

* 앱의 화면 구조를 페이지 단위로 설계합니다. 예) 1. 시작 화면, 2. 게임 화면, 3. 결과 화면
* 페이지를 지정하지 않으면 프롬프트에서 AI 자율 구성으로 안내합니다.

6. 프롬프트 생성

* 입력한 모든 내용을 바탕으로 AI 요청 문장을 한 번에 생성합니다.
* 복사 버튼으로 즉시 클립보드에 복사하거나, TXT로 저장할 수 있습니다.
* 선택적으로 README.md로 저장하는 버튼을 추가해 프로젝트 설명서를 내려받을 수 있습니다.

## 사용 방법

1. index.html을 브라우저에서 직접 열기
2. 기본 정보, 디자인, 기능, 페이지를 차례로 입력
3. 프롬프트 생성 버튼 클릭
4. 복사 또는 저장 버튼으로 결과 활용
5. 예시 불러오기를 눌러 샘플 데이터를 바탕으로 구조를 먼저 익힐 수 있습니다.
6. 초기화 버튼으로 모든 입력을 한 번에 비울 수 있습니다.



## 접근성과 사용성 원칙

* 키보드 포커스와 Enter 동작으로 추가가 가능하도록 이벤트를 제공합니다.
* 버튼, 칩, 스와치의 aria-label과 aria-pressed를 통해 상태를 명확하게 노출합니다.
* 색상 선택은 시각 톤 확인을 위한 칩과 코드 표기를 함께 제공합니다.
* 권한 요청(마이크, 카메라 등)이 필요한 경우 반드시 사용자의 클릭 이벤트 이후에만 요청하도록 안내합니다.



## 기술 스택

* HTML 하나의 파일에 HTML, CSS, JS가 모두 포함되는 단일 파일 구조
* Tailwind CSS CDN
* Google Fonts 다중 로딩
* 순수 JavaScript로 상태 관리와 UI 렌더링

## 커스터마이징 팁

* 색상 팔레트는 pastel, vivid, nature, mono 중에서 선택할 수 있으며, 필요 시 팔레트 배열에 원하는 색상을 추가할 수 있습니다.
* 글씨체는 FONT\_MAP 상수에서 쉽게 추가/제거할 수 있습니다.
* 모달 메시지, 버튼 문구 등 UI 텍스트는 한국어 학급 맥락에 맞게 자유롭게 수정하세요.



## 자주 묻는 질문

Q. 출력된 프롬프트를 그대로 다른 AI에게 붙여넣어도 되나요
A. 네. 단일 HTML 파일을 생성하도록 안내되어 있어, 빠르게 초기 프로토타입을 만들기에 적합합니다.

Q. 페이지 구성을 비워두면 어떻게 되나요
A. 프롬프트에 AI 자율 구성으로 안내되어, 도구가 적절한 화면 구성으로 제안할 수 있습니다.
