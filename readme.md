# 가이드 바이브! ✊✌️✋

AI와 함께하는 나만의 앱 만들기 도우미

가이드 바이브!는 머릿속에 있는 앱 아이디어를 정리해, AI가 한 번에 알아들을 수 있는 요청 문장(프롬프트)으로 바꿔주는 단일 HTML 웹앱입니다. 초등학생도 쉽게 사용할 수 있도록 친근한 UI와 단계적 구조를 갖췄습니다.

---

## 주요 기능

1. **기본 정보 입력** — 앱 이름, 주요 사용자, 한 줄 소개로 아이디어의 정체성을 정의합니다.
2. **디자인 설정** — 전체 분위기, 대표 색상(최대 5색), 글씨체(최대 3종)를 시각적으로 선택합니다.
3. **주요 기능 카드** — 기능 이름 / What / How / 추가 설명을 카드 단위로 구조화합니다.
4. **보조 기능 정리** — 효과음·튜토리얼·점수 저장 등 "있으면 좋은" 기능을 모아 둡니다.
5. **화면 만들기** — 실제 앱 프로토타입처럼 휴대폰 모양 화면을 직접 만들고, 화면 위에 바로 글씨를 써서 자유롭게 설계합니다. 화살표로 순서를 바꾸면 번호가 자동으로 매겨지고, 비워두면 AI 자율 구성에 맡깁니다.
6. **프롬프트 자동 생성** — 입력한 모든 내용을 한 번에 AI 요청 문장으로 변환하여 복사 또는 TXT로 저장합니다.
7. **JSON 저장·불러오기** — 현재 작업 상태를 JSON 파일로 내보내고, 다시 불러와 이어 작업할 수 있습니다.
8. **자동 저장** — 입력 내용이 브라우저 localStorage에 자동 저장되어, 새로고침 후에도 유지됩니다.
9. **한국어·영어 전환** — 한 번의 클릭으로 인터페이스 언어를 전환합니다.

---

## 사용 방법

1. `index.html`을 브라우저에서 열어주세요.
2. 화면 상단의 **설명서** 버튼으로 사용법을 먼저 확인합니다.
3. 기본 정보 → 디자인 → 주요 기능 → 보조 기능 → 화면 만들기를 차례로 입력합니다.
4. **프롬프트 생성** 버튼을 누르면 하단에 AI 요청 문장이 나타납니다.
5. **복사** 또는 **TXT로 저장** 버튼으로 결과를 활용합니다.
6. 처음 사용한다면 **예시 불러오기**로 샘플 데이터 구조를 먼저 살펴보는 것을 추천합니다.
7. 처음부터 다시 시작하려면 **초기화** 버튼을 누릅니다.

## 화면 구성

- **헤더** — 타이틀, 언어 전환 / JSON 내보내기·불러오기(아이콘), 설명서 / 예시 불러오기 / 초기화 버튼
- **본문 카드** — 기본 정보, 디자인, 주요 기능, 보조 기능, 화면 만들기, 프롬프트 출력 영역
- **푸터** — 제작자 링크

## 디자인 시스템

- **아이콘** — Google Material Symbols Rounded
- **타이틀 폰트** — Black Han Sans
- **본문 폰트** — Noto Sans KR
- **선택 가능한 한글 폰트** — 본고딕, 나눔고딕, 나눔명조, 도현체, 주아체, 동글체, 구기체, 기랑해랑, 디필레이아, 그랜드플로라
- **색상 팔레트** — 파스텔 / 알록달록(비비드) / 자연 / 무채색 4종

## 기술 스택

- 단일 HTML 파일 구조(HTML/CSS/JS 내장)
- Tailwind CSS CDN
- Google Fonts (Noto Sans KR, Black Han Sans, 한글 폰트 10종)
- Google Material Symbols Rounded
- 순수 JavaScript (별도 빌드 도구 불필요)
- localStorage 기반 자동 저장

## 접근성·사용성

- 키보드 Enter 키로 카드/항목 추가
- 모든 모달 ESC 키로 닫기 지원

## 자주 묻는 질문

**Q. 출력된 프롬프트를 그대로 다른 AI에게 붙여넣어도 되나요?**
A. 네. 단일 HTML 파일을 생성하도록 구조화되어 있어, 초기 프로토타입 제작에 적합합니다.

**Q. 화면 만들기를 비워두면 어떻게 되나요?**
A. 프롬프트에 "AI 자율 구성"으로 안내되어, AI가 적절한 화면 흐름을 제안하도록 합니다.

**Q. 작업하던 내용이 사라지나요?**
A. localStorage에 자동 저장되어 새로고침 후에도 유지됩니다. 다른 기기로 옮길 때는 JSON 내보내기/불러오기를 사용하세요.
