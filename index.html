💡 가이드 바이브 설명서!

안녕, 여러분! 👋
'가이드 바이브!'는 가위바위보를 하듯이
쉽고 재밌게 너만의 멋진 앱 아이디어를
AI에게 쉽게 설명해주기 위한 도구야!
아래 순서대로 따라 해보자!

☁️ 1. 기본 정보 입력하기

  • 🤔
    앱 이름: 만들고 싶은 앱의 이름을 지어보자! (예: 우주 탐험대)
  • 🧑‍🤝‍🧑
    주요 사용자: 이 앱을 누가 쓸까? (예: 별을 좋아하는 5학년)
  • 💖
    앱 소개하기: 어떤 앱인지 한 줄로 멋지게 소개해줘!

🌈 2. 디자인 정하기

  • 🎨
    전체 분위기: 앱이 어떤 느낌이면 좋을까? (예: 신나고 재미있는 느낌)
  • 🖌️
    대표 색: 마음에 드는 색을 5개까지 골라봐!
  • ✍️
    글씨체: 앱에 어울리는 글씨체를 3개까지 골라봐!

⭐ 3. 주요 기능 만들기

  • 💡
    기능 이름: 앱의 가장 중요한 기능을 알려줘! (예: 행성 찾기)
  • 🗺️
    설명(What): 이 기능이 무엇을 하는지 적어줘. (예: 태양계 행성 정보를 보여줘요)
  • 👉
    동작/방법(How): 어떻게 사용하는 걸까? (예: 행성 그림을 클릭하면 설명이 나와요)
  • ✨
    추가 설명: 더 필요한 게 있다면 적어줘!

🎵 4. 보조 기능 추가하기 (선택!)

  • 🔊
    "신나는 배경음악", "점수 저장하기" 처럼 있으면 더 좋을 것 같은 기능을 적어줘!

📄 5. 페이지 구성하기 (심화!)

  • 🏠
    앱이 어떤 화면(페이지)으로 보일지 순서대로 적어보자! (안 적으면 AI가 알아서 해줄 거야!)
  • 🖼️
    예) '1. 시작 화면', '2. 게임 화면', '3. 점수 화면' ...

🤖 6. 프롬프트 생성!

  • 🚀
    '프롬프트 생성' 버튼을 누르면, 너의 아이디어가 AI가 알아들을 수 있는 멋진 '요청 문장'으로 변신해!
  • 📋
    '복사' 버튼을 눌러서 AI에게 바로 물어보러 가자!
