lightbulb 어떤 화면이 필요할지 모르겠다면?

6 smart_toy AI 요청 문장(프롬프트)

created by. 교육뮤지컬 꿈꾸는 치수쌤

menu_book 가이드 바이브 사용법

가이드 바이브는 앱 아이디어를 정리해
AI가 이해하기 쉬운 요청 문장(프롬프트)으로 바꿔주는 도구입니다.
아래 순서대로 따라가 보세요.

info 1. 기본 정보

  • apps
    앱 이름 — 만들고 싶은 앱의 이름을 적습니다. (예: 우주 탐험대)
  • groups
    주요 사용자 — 누가 사용할지를 적습니다. (예: 별을 좋아하는 5학년)
  • campaign
    앱 소개 — 어떤 앱인지 한 줄로 소개합니다.

palette 2. 디자인

  • mood
    전체 분위기 — 앱의 느낌을 한 줄로 적습니다. (예: 신나고 재미있는 느낌)
  • format_color_fill
    대표 색상 — 최대 5개까지 선택할 수 있습니다.
  • text_fields
    글씨체 — 어울리는 글씨체를 최대 3개까지 고릅니다.

star 3. 주요 기능

  • lightbulb
    기능 이름 — 앱의 핵심 기능 이름을 적습니다. (예: 행성 찾기)
  • description
    설명 (What) — 이 기능이 무엇을 하는지 설명합니다. (예: 태양계 행성 정보를 보여줍니다)
  • touch_app
    동작 방법 (How) — 어떻게 사용하는지 적습니다. (예: 행성을 클릭하면 설명이 나타납니다)
  • add_circle
    추가 설명 — 보충이 필요한 내용을 적습니다. (선택)

tune 4. 보조 기능 (선택)

  • music_note
    있으면 좋은 보조 기능을 적습니다. (예: 배경음악, 점수 저장, 튜토리얼)

smartphone 5. 화면 만들기

  • edit
    ‘새 화면 만들기’를 누르면 휴대폰 화면이 생겨요. 화면 위에 이름과 할 일을 바로 적어 보세요. 내 앱에 맞게 자유롭게요!
  • swap_horiz
    화살표(◀ ▶)로 화면 순서를 바꾸면 번호가 자동으로 매겨져요. 비워두면 AI가 자율 구성합니다.

smart_toy 6. 프롬프트 생성

  • auto_awesome
    프롬프트 생성 버튼을 누르면 입력한 내용이 AI 요청 문장으로 변환됩니다.
  • content_copy
    복사 버튼으로 클립보드에 담아 AI 챗봇에 붙여 넣어 사용합니다.
